# SmartShop

אפליקציית רשימת קניות משותפת, בהזמנה בלבד. כל קבוצה (משפחה) מנהלת את הרשימות שלה, ואין שום גישה בין קבוצות.

- **כתובת:** https://smartshop-c58a5.web.app
- **טכנולוגיה:** קובץ HTML יחיד (PWA) + Firebase Realtime Database + Firebase Auth (Google) + App Check (reCAPTCHA v3)
- **פרויקט Firebase:** `smartshop-c58a5`

## תפקידים

| פעולה | מנהל-על (admin) | מנהל קבוצה | חבר בקבוצה |
|---|---|---|---|
| מינוי והסרה של מנהלי קבוצות | ✓ | ✗ | ✗ |
| הזמנת אנשים לקבוצה (קישור הזמנה) | ✓ | ✓ | ✗ |
| הוצאת משתתף מהקבוצה | ✓ | ✓ | ✗ |
| יצירת רשימות | ✓ ללא הגבלה | ✓ עד 20 | ✓ עד 10 |
| שיתוף רשימה עם חברי הקבוצה | ✓ | ✓ | ✓ |
| שיתוף רשימה מחוץ לקבוצה | ✗ | ✗ | ✗ |

- קבוצה כוללת עד **10 משתתפים**, כולל המנהל.
- משתמש יכול להיות חבר בקבוצה אחת בלבד.
- מי שאינו מנהל ולא הצטרף לקבוצה רואה מסך "האפליקציה בהזמנה בלבד".
- המנהל-על מוגדר בקוד (`ADMIN_EMAILS` ב-`smartshop.html`) וגם בחוקים (`database.rules.json`). אם משנים אותו, צריך לשנות בשני המקומות.

## הפצה

### מינוי מנהל קבוצה חדש
1. באפליקציה: תפריט ⋯ ← **ניהול** ← **מנהלי קבוצות** ← מזינים את מייל ה-Google שלו ← **הוסף**.
2. שולחים לו את הכתובת הרגילה, **לא** קישור הזמנה לקבוצה קיימת.
3. בכניסה הראשונה שלו נוצרת לו קבוצה אוטומטית.

### הזמנת משתתפים לקבוצה (מנהל הקבוצה)
- **הזמנה:** תפריט ⋯ ← **הקבוצה שלי** ← **שלח הזמנה בוואטסאפ** או **העתק קישור הזמנה**.
- **החלפת קישור:** הכפתור **החלף קישור** מבטל את הקישור הקודם. מי שכבר בקבוצה נשאר בה.
- **הוצאת משתתף:** הכפתור **הוצא** מסיר את המשתתף. הוא מאבד מיד גישה לכל רשימות הקבוצה, וקישור ההזמנה מוחלף אוטומטית.

### שיתוף רשימה
בתוך רשימה פתוחה: תפריט ⋯ ← **שיתוף הרשימה**, ומסמנים את חברי הקבוצה שיראו אותה. רק מי שיצר את הרשימה יכול לשתף אותה.

### התקנה בטלפון
אותו קישור עובד בשתי המערכות, ואין צורך בחנות אפליקציות.
- **אנדרואיד:**
  1. פותחים את הקישור ב-Chrome ונכנסים עם Google.
  2. מתקינים: תפריט ⋯ ← **התקן אפליקציה**, או בתפריט של Chrome ← **הוספה למסך הבית**.
- **אייפון:**
  1. פותחים את הקישור ב-Safari ונכנסים עם Google.
  2. מוסיפים למסך הבית: שיתוף ← **הוספה למסך הבית**.
  3. פותחים מהאייקון ומתחברים שוב. באייפון, ההתחברות לא עוברת בין Safari לאפליקציה שבמסך הבית.
- **אם ההתחברות עם Google נחסמת:** הקישור נפתח בדפדפן פנימי של אפליקציה אחרת (פייסבוק, אינסטגרם וכו'). פותחים אותו ב-Chrome או ב-Safari.

## מבנה הנתונים (`/smartshop`)

```
managers/{email עם , במקום .}  { email, ts }                 — רק admin כותב
groups/{gid}                     owner, ownerKey, name, inviteToken,
                                 memberCount, lastRemoved,
                                 members/{uid} { name, email, ts },
                                 joins/{uid} = token
users/{uid}                      group, lists/{listId}, shared/{listId},
                                 owned/{listId}, ownedCount, ownedOp
{listId}                         meta { owner, group, name, createdAt },
                                 members/{uid}, items/{itemId}, presence/{clientId}
global/products                  קטלוג מוצרים משותף — כולם קוראים, רק admin כותב
```

- **מזהים:** קבוצה `g_` + 12 תווים הקסדצימליים, רשימה `sl_` + 12 תווים הקסדצימליים. רשימות ישנות שומרות על הפורמט הקודם שלהן.
- **פעולות אטומיות:** הצטרפות, הוצאה, יצירת רשימה ומחיקת רשימה נכתבות כ-multi-path update אחד. החוקים בודקים שהמונים (`memberCount`, `ownedCount`) משתנים בדיוק ב-1 יחד עם הרשומה המתאימה, כך שאי אפשר לעקוף את המכסות.
- **גישה לרשימה** מותרת רק למי שהוא בעלים או חבר ברשימה **וגם** חבר בקבוצה של הרשימה. לכן הוצאה מהקבוצה מבטלת מיד את הגישה לכל הרשימות של הקבוצה.

## פיתוח ופריסה

1. עורכים את `smartshop.html`.
2. מעתיקים אותו ל-`public/index.html`.
3. פורסים, תמיד עם `--project`:
   ```
   firebase deploy --only hosting,database --project smartshop-c58a5
   ```
4. מבצעים commit ו-push.

אחרי פריסה צריך לבצע hard refresh, או לסגור ולפתוח את האפליקציה מהמסך הראשי.

### בדיקות חוקים
כל שינוי ב-`database.rules.json` או בזרימות הכתיבה צריך לעבור את הבדיקות באמולטור לפני פריסה. הבדיקות דורשות Java 11 ומעלה.

```
cd tests
cp ../database.rules.json .
npm i -D @firebase/rules-unit-testing@4 firebase@11
firebase emulators:exec --only database --project smartshop-test "node rules.test.js"
```

### גיבוי
לפני שינוי נתונים ידני שומרים עותק של המסד:
```
firebase database:get /smartshop --project smartshop-c58a5 > .backups/db_<date>.json
```
התיקייה `.backups/` לא נכנסת ל-git.
